# Pipeline éditorial contrôlé

Source 1 pour le livre, Source 2 pour le langage visuel, Arena Agent pour la production.

## Règle

- Le PDF QUELLE SOCIÉTÉ APRÈS L’IA -draft.pdf est la seule source de vérité éditoriale.
- Le PDF tets2.pdf est une référence de direction artistique, pas une source de contenu.
- Arena Agent orchestre la chaîne de production.

## Ce qui compte

Le livre doit être construit à partir du vrai manuscrit : structure, arguments, chapitres, conclusion, questions, épilogue et bibliographie.

Les pages de planification, objectifs, estimations et checkpoints du premier PDF sont utiles comme contexte de production, mais ne doivent pas devenir des pages du livre.

## Ce qu’on garde de tets2.pdf

On garde son système visuel :

- mise en page intérieure,
- intercalaires de parties,
- hiérarchie typographique,
- boîtes de citation et de concept,
- rythme visuel et transition entre chapitres.

## Ce qu’on corrige

La couverture de tets2.pdf ne correspond pas au titre principal ni aux crédits souhaités. Elle doit être retravaillée pour refléter le vrai livre, sans copier aveuglément la référence.

## Workflow

draft → extraction du vrai contenu → direction artistique de tets2 → composition → compilation → inspection visuelle → correction

## Résultat attendu

- contenu éditorial : source unique et stable,
- style visuel : inspiré d’une référence maîtrisée,
- production : contrôlée, cohérente, sans contamination entre le livre et son contexte de fabrication.
